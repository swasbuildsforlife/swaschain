# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in SwasChain, please report it privately rather than opening a public issue.

Include:

- A clear description of the issue
- Steps to reproduce the behavior
- The affected component
- Any relevant logs or test cases

Please avoid sharing private keys, credentials, or other sensitive information in reports.

## Security Principles

SwasChain development prioritizes:

- Deterministic protocol behavior
- Explicit validation rules
- Safe handling of cryptographic material
- Testable state transitions
- Minimal exposure of sensitive information
